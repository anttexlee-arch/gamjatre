# 감자트리 브랜드 홈페이지

지중해식 수입 가공식품 브랜드 **감자트리**의 반응형 정적 웹사이트입니다.

## 구성

- 홈 (`index.html`)
- 내 소개 (`about.html`)
- 제품 (`products.html`)
- 이야기 (`stories.html`)
- 연락하기 (`contact.html`)

별도의 빌드 과정 없이 `index.html`을 브라우저로 열면 바로 확인할 수 있습니다.

## 수정하기

- 페이지 문구: 각 HTML 파일
- 색상과 레이아웃: `assets/style.css`
- 모바일 메뉴와 폼 안내: `assets/main.js`

현재 연락처, 제품 상세, 가격, 게시글 내용은 자연스러운 임시 문구로 채워져 있습니다.
